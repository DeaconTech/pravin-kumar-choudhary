# YouTube Technology Content Manager

A professional web application for creating and managing YouTube technology content with ISO-compliant standards and trending tags.

## 🚀 Quick Start

```bash
cd youtube-content-manager
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start creating content!

## ✨ Features

### Core Functionality
- ✅ **Video Metadata Management** - Complete title, description, and tag management
- ✅ **ISO 8601 Compliance** - Professional date/time formatting
- ✅ **ISO 639-1 Language Codes** - 8 major languages supported
- ✅ **Trending Tech Tags** - 8 categories with 50+ pre-populated tags
- ✅ **Smart Tag Optimizer** - Respects YouTube's 15 tag, 500 character limits
- ✅ **Export Functionality** - Copy-ready format for YouTube Studio
- ✅ **Live Preview** - See your content before publishing
- ✅ **Character Counters** - Real-time tracking for all YouTube limits

## 📊 YouTube Limits Enforced

| Element | Limit | Enforced |
|---------|-------|----------|
| Title | 100 characters | ✅ |
| Description | 5000 characters | ✅ |
| Tags | 15 maximum | ✅ |

## 📝 Example Workflow

1. **Enter Video Details**
   - Add compelling title (max 100 chars)
   - Write detailed description (max 5000 chars)
   - Select language (ISO 639-1)
   - Set publish date (ISO 8601)

2. **Add Tags**
   - Browse 8 trending categories
   - Click to add instantly
   - Or add custom tags
   - Max 15 tags, 500 chars

3. **Preview & Export**
   - Review in preview panel
   - Click "Copy for YouTube Studio"
   - Paste into YouTube when uploading
